# Isla v1.7.0

首个公开版本（build 110）。

## 新增

- **App 内更新**：设置 → 关于或菜单栏「检查更新…」可以检查新版本。
  - **下载安装包**：把 DMG 下载到「下载」文件夹并在 Finder 中定位。
  - **直接更新并重启**：下载 ZIP、校验 SHA-256 与 Ed25519 签名、替换 App 并自动重启。
  - 支持启动后每 24 小时自动检查；安装前仍会确认，不会静默替换。
- **开源**：MIT License，源码在 https://github.com/LLllCCC/Isla 。

## 改进

- 形态命名对齐：「居中垂帘」占用真实菜单栏槽位、固定不可拖动，不会盖住其它图标；
  「菜单栏胶囊」是纯浮层，可直接左右拖动。
- 更新包与 appcast 均使用 Ed25519 签名；App 内固定公钥并校验下载包的证书。

## 说明

- 当前为自签、未公证版本。首次打开若被 Gatekeeper 拦截，请到
  「系统设置 → 隐私与安全性」点「仍要打开」。
- 更新使用同一张自签证书签名，辅助功能授权、登录项、设置和插件数据会保留。
- 系统要求：macOS 14+。
