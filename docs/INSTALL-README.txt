Isla 1.7.0（build 110）
════════════════════════════════════════════════════════════

【安装】
1) 把 Isla.app 拖进「应用程序」文件夹。
2) 双击打开。如果 macOS 提示「无法验证开发者」：
   → 打开「系统设置 → 隐私与安全性」，点「仍要打开」。
   （这是自签名版本、没有 Apple 公证，所以第一次要手动确认一次；
     之后就能正常双击启动，升级也不会再拦。）
3) 首次运行会申请「辅助功能」权限：
   系统设置 → 隐私与安全性 → 辅助功能 → 打开 Isla 的开关。
   · 授权后：菜单栏胶囊会避开系统图标，播放/暂停能即时判定。
   · 不授权也能用：胶囊会落到屏幕正中，暂停判定最慢 8 秒。

【更新】
· 设置 → 关于 → 检查更新：
  - 「直接更新并重启」：App 内下载、校验并替换，自动重启；
  - 「下载安装包」：把 DMG 下载到「下载」文件夹，自己拖进「应用程序」覆盖。
· 也可以到 GitHub Releases 手动下载最新 DMG：
  https://github.com/LLllCCC/Isla/releases/latest
· 自签身份保持不变，辅助功能授权会保留，不用重新授权。

【卸载】
· 把 Isla.app 拖进废纸篓。
· 想彻底清理（可选）：删除
  ~/Library/Application Support/Isla
  ~/Library/Logs/Isla

【插件商店（官方示例源，带发布者签名）】
https://llllccc.github.io/Isla/index.json
· 索引带 Ed25519 发布者签名，App 内置官方公钥，下载即校验；
  换钥匙或签名被去掉会直接拒绝加载。
· 插件只能拿到 manifest 里声明的权限，安装时逐项向你确认。

【校验安装包】
· 本机可执行：shasum -a 256 Isla-1.7.0-110.dmg
· 校验值随 Release 公告一起给出。
